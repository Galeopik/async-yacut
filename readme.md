# YaCut

YaCut — учебный сервис для сокращения ссылок и загрузки файлов с возможностью получения коротких ссылок.

Проект разработан на Flask в рамках обучения backend-разработке. Приложение позволяет создавать короткие ссылки для обычных URL, задавать собственные идентификаторы, переходить по коротким ссылкам, а также загружать файлы на Яндекс Диск и получать короткие ссылки на загруженные файлы.

## Возможности

* создание коротких ссылок для длинных URL;
* автоматическая генерация уникального короткого идентификатора;
* возможность указать собственный идентификатор короткой ссылки;
* проверка уникальности коротких идентификаторов;
* валидация пользовательских идентификаторов;
* переход по короткой ссылке с перенаправлением на исходный URL;
* REST API для создания коротких ссылок;
* интерактивная документация API;
* обработка ошибок API с возвратом JSON-ответов;
* загрузка нескольких файлов на Яндекс Диск;
* асинхронная обработка загрузки файлов;
* автоматическое создание коротких ссылок для загруженных файлов;
* использование SQLAlchemy для работы с базой данных;
* Flask-WTF для работы с HTML-формами;
* разделение логики между представлениями, формами и моделью;
* автоматическое тестирование проекта;
* проверка качества кода с помощью Flake8.

## Создание коротких ссылок

Пользователь может создать короткую ссылку двумя способами.

### Автоматическая генерация

Если пользователь не указывает собственный идентификатор, приложение автоматически генерирует уникальный идентификатор.

Идентификатор состоит из латинских букв и цифр.

### Пользовательский идентификатор

Пользователь может самостоятельно указать короткий идентификатор.

Для него выполняются проверки:

* длина не превышает установленного ограничения;
* используются только допустимые символы;
* идентификатор отсутствует в базе данных;
* идентификатор не конфликтует с зарезервированными именами приложения.

При некорректном значении пользователь получает сообщение об ошибке.

## Переход по короткой ссылке

При переходе по короткой ссылке приложение выполняет поиск соответствующей записи в базе данных.

Если ссылка найдена, пользователь перенаправляется на исходный URL.

Если короткая ссылка не существует, возвращается страница ошибки `404`.

## Работа с файлами

YaCut позволяет загружать файлы через отдельную форму.

Загрузка файлов выполняется асинхронно с использованием `aiohttp`.

Процесс загрузки:

1. пользователь выбирает один или несколько файлов;
2. приложение отправляет запрос к API Яндекс Диска для получения ссылки на загрузку;
3. файл загружается на Яндекс Диск;
4. приложение получает ссылку на загруженный файл;
5. для ссылки автоматически создаётся короткий идентификатор;
6. информация сохраняется в базе данных;
7. пользователю отображается короткая ссылка на файл.

Для нескольких файлов используется асинхронная обработка запросов.

## REST API

В проекте реализован API для создания коротких ссылок.

### Создание короткой ссылки

```POST /api/id/```

Пример запроса:

```json
{
    "url": "https://example.com/very/long/url",
    "custom_id": "example"
}
```

Поле `custom_id` является необязательным.

Если оно не передано, приложение автоматически генерирует уникальный идентификатор.

Пример ответа:

```json
{
    "url": "https://example.com/very/long/url",
    "short_link": "http://127.0.0.1:5000/example"
}
```

### Ошибки API

При некорректном запросе API возвращает JSON с описанием ошибки.

Например:

```json
{
    "message": ""url" является обязательным полем!"
}
```

Для обработки ошибок используется собственное исключение `InvalidAPIUsageError`.

## Формы

Для работы с пользовательским вводом используется Flask-WTF.

В проекте используются формы для:

* создания короткой ссылки;
* загрузки файлов.

Валидация пользовательского идентификатора выполняется отдельно и проверяет соответствие установленному формату.

Правила валидации вынесены в константы, чтобы изменение требований не требовало поиска и изменения одинаковых значений по всему проекту.

## Работа с базой данных

Для взаимодействия с базой данных используется SQLAlchemy.

Операции с моделью `URLMap` вынесены в методы модели. Представления отвечают преимущественно за обработку HTTP-запросов и формирование ответов.

Такое разделение позволяет не дублировать операции с базой данных в разных представлениях.

При возникновении ошибки во время сохранения данных выполняется откат транзакции.

## Обработка ошибок

В проекте реализованы обработчики основных ошибок приложения:

* `400 Bad Request` — некорректный запрос к API;
* `404 Not Found` — короткая ссылка не найдена;

Для API ошибки возвращаются в формате JSON.

Для обычных страниц используются HTML-шаблоны ошибок.

## Асинхронность

Для загрузки нескольких файлов используется асинхронное программирование Python.

Взаимодействие с API Яндекс Диска выполняется с помощью `aiohttp`.

Для параллельного выполнения нескольких операций используется `asyncio.gather()`.

Это позволяет выполнять операции загрузки нескольких файлов асинхронно.

## Установка и запуск

### 1. Клонировать репозиторий

```git clone git@github.com:Galeopik/async-yacut.git```
```cd async-yacut```

### 2. Создать виртуальное окружение

Windows:

```python -m venv venv```

Linux / macOS:

```python3 -m venv venv```

### 3. Активировать виртуальное окружение

Windows:

```venv\Scripts\activate```

Linux / macOS:

```source venv/bin/activate```

### 4. Установить зависимости

```pip install -r requirements.txt```

### 5. Настроить переменные окружения

Для работы с Яндекс Диском необходимо указать OAuth-токен.

Например:

```DISK_TOKEN=your_yandex_disk_token```

Также необходимо указать остальные параметры приложения, предусмотренные конфигурацией проекта.

### 6. Выполнить миграции

Если проект использует Flask-Migrate, выполните:

```flask db upgrade```

### 7. Запустить приложение

```flask run```

После запуска приложение будет доступно по адресу:

[Ссылка](http://127.0.0.1:5000/)
